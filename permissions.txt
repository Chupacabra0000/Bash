The mkdir -m (or --mode) option is used to set specific file permissions (read, write, and execute) for a directory at the exact moment you create it.
By default, when you run mkdir folder_name, Linux assigns permissions based on your system's default permission mask (called umask). Using the -m option bypasses or overrides that default behavior, allowing you to explicitly dictate who can access or modify the new directory.
------------------------------
## Understanding the Syntax
The option accepts permissions in two formats: Numeric (Octal) or Symbolic (Characters).
## 1. Numeric (Octal) Format
This uses three digits to represent permissions for the Owner, Group, and Others.

* 7 = Read, Write, and Execute (rwx)
* 6 = Read and Write (rw-)
* 5 = Read and Execute (r-x)
* 4 = Read only (r--)
* 0 = No permissions (---)

# Create a private folder where ONLY the owner can read, write, and access it
mkdir -m 700 private_records
# Create a shared folder where everyone can read and enter, but only the owner can modify
mkdir -m 755 public_shares
# Create a highly restrictive folder where the owner can modify, group can read, others get nothing
mkdir -m 740 department_vault

## 2. Symbolic Format
This uses letters (u for user/owner, g for group, o for others, a for all) and mathematical signs (= to set, + to add, - to remove).

# Set permissions so everyone has full access
mkdir -m a=rwx open_folder
# Give the owner full access, but explicitly remove write access from group and others
mkdir -m u=rwx,go=rx strict_folder

------------------------------
## mkdir -m vs. chmod
Normally, changing permissions is a two-step process: you create the directory and then change its permissions using chmod.

# The two-step method
mkdir secure_dir
chmod 700 secure_dir

Using mkdir -m combines this into a single, atomic command:

# The one-step method
mkdir -m 700 secure_dir

## Why use mkdir -m?

* Security: In automation scripts, there is a tiny fraction of a second between running mkdir and chmod. During that window, a directory exists with looser default system permissions. Using mkdir -m 700 ensures the directory is secure from the exact millisecond it is created.
* Efficiency: It saves lines of code in bash scripts and prevents you from typing multiple commands.

Calculating octal permission numbers is straightforward once you memorize three basic numbers and understand the three target groups.
To get an octal digit, you simply add up the points for the permissions you want to grant.
------------------------------
## 1. The Point Values (The Building Blocks)
Every individual permission has a fixed numeric score:

* 🟢 4 = Read (r) — Permission to see the folder contents.
* ✍️ 2 = Write (w) — Permission to create, delete, or rename files inside.
* 🏃 1 = Execute (x) — Permission to enter (cd into) the directory.
* ❌ 0 = None — No permissions at all.

------------------------------
## 2. The Three Target Groups
An octal permission setting consists of three digits in a row. The order strictly represents who gets the permissions:

| Digit Position | Target Group | Who they are |
|---|---|---|
| First Digit | User (u) | The individual owner who created the directory. |
| Second Digit | Group (g) | Members of the team/group assigned to the directory. |
| Third Digit | Others (o) | Everyone else on the system (the public). |

------------------------------
## 3. Let's Calculate Common Examples
To find a digit, add the values together: Read (4) + Write (2) + Execute (1).
## Example A: Full public access (755)

* User: Needs Read (4) + Write (2) + Execute (1) = 7
* Group: Needs Read (4) + Execute (1) = 5
* Others: Needs Read (4) + Execute (1) = 5
* Result: 755 (Command: mkdir -m 755 folder)

## Example B: Total lockdown / Private (700)

* User: Needs Read (4) + Write (2) + Execute (1) = 7
* Group: Needs nothing = 0
* Others: Needs nothing = 0
* Result: 700 (Command: mkdir -m 700 folder)

## Example C: Collaborative group folder (770)

* User: Needs Read (4) + Write (2) + Execute (1) = 7
* Group: Needs Read (4) + Write (2) + Execute (1) = 7
* Others: Needs nothing = 0
* Result: 770 (Command: mkdir -m 770 folder)

------------------------------
## Scannable Cheat Sheet

* 7 (rwx) = Full access (Read + Write + Execute)
* 6 (rw-) = Read and Write (Rare for directories, common for files)
* 5 (r-x) = Read and Enter (Read + Execute)
* 4 (r--) = Read only
* 0 (---) = No access

(Note: For directories, you almost always want to pair Read with Execute. If you give a directory Read (4) but not Execute (1), a user can see the file names inside but cannot actually open or use them!)
